# TBS Portal Showcase Repository

This repository contains documentation and architecture details for the TBS Portal project.

## Repository Structure

```
showcase/
├── README.md           # Project overview and key metrics
├── ARCHITECTURE.md     # Technical architecture and database schema
├── FEATURES.md         # Detailed feature documentation
├── ROADMAP.md          # Development milestones and timeline
└── .gitignore          # Git ignore rules
```

## Purpose

This is a **public showcase repository** for the TBS Portal project. It contains:

- Project documentation
- Architecture diagrams
- Feature descriptions
- Development roadmap
- Technical specifications

**No source code is included** in this repository. The actual codebase is in a private repository.

## Live Application

**Portal:** [tbsportal.tn](https://tbsportal.tn)

## Tech Stack

- **Frontend:** Next.js 16, TypeScript, Tailwind CSS
- **Backend:** FastAPI, Python 3.10, SQLAlchemy
- **Database:** PostgreSQL 16 + pgvector
- **AI:** Azure OpenAI (GPT-4o, text-embedding-3-small)
- **Hosting:** Azure App Service
